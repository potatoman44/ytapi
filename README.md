# Save One Song

Pick one song per year (or per month by decade, or by genre, scene, artist or album) from Album of the Year's users' top songs (1963–2026; 200+ ratings before 2000, 500+ from 2000, plus a few hand-picked songs). Each song plays a 30-second Deezer clip (preloaded, instant); FULL SONG plays it on YouTube.

Play: https://save-one-song.pages.dev/
